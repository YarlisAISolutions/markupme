# Keyboard formatting

| Keys | Action |
| --- | --- |
| Ctrl+B (Cmd+B) | Bold |
| Ctrl+I (Cmd+I) | Italic |
| Alt+S | Strikethrough |
| Ctrl+Alt+M (Cmd+Alt+M) | Open preview to the side |

The formatting keys work only in Markdown files, and only when `markupme.editor.shortcuts` is on. They are off by default because VS Code uses Ctrl+B for the sidebar, and VS Code and Cursor use Cmd+I for inline chat.

With nothing selected, a toggle works on the word under the cursor. Run it again to remove the formatting.
