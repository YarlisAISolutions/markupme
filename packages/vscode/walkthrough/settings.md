# Settings

| Setting | What it does |
| --- | --- |
| `markupme.preview.theme` | `auto`, `light` or `dark` |
| `markupme.markdown.math` | KaTeX math |
| `markupme.markdown.emoji` | `:shortcode:` emoji |
| `markupme.diagrams.providers` | Which diagram renderers run |
| `markupme.format.enable` | MarkupMe as your Markdown formatter (format on save) |
| `markupme.validate.rules` | Rule severities |

In an untrusted workspace, rendering stays sanitized and Kroki stays off, whatever the workspace settings say.
